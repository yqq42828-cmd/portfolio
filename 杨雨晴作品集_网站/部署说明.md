# 怎么把这个网站变成可以分享的链接

网站是纯静态的（HTML + CSS + JS + 图片），没有后端、不需要数据库，所以**任何静态托管服务都能直接放上去**。

包已经准备好：`杨雨晴作品集_网站.zip`（6.9 MB，74 个文件，解压后顶层就是 `index.html`）。

---

## 最快的方式：Netlify Drop（拖拽上传，不用注册账号也能先试）

1. 打开 <https://app.netlify.com/drop>
2. 把 **解压后的整个文件夹** 拖进页面（不要拖 zip，要拖解压出来的文件夹）
3. 等十几秒，页面会给你一个 `https://xxxx-yyyy.netlify.app` 的链接
4. 这个链接可以直接发给别人

- 想保留、想改名字：注册一个免费账号，之后可以把链接改成 `yangs-yuqing.netlify.app` 这样的子域名
- 免费额度：100 GB 流量/月，个人作品集完全够用

---

## 想把链接做得更正式：GitHub Pages

适合以后还想继续改代码的情况。

1. 注册/登录 GitHub，新建一个仓库，名字随意（例如 `portfolio`）
2. 把解压后的所有文件上传到仓库根目录（网页版直接拖拽即可，或用 git 命令）
3. 进仓库 `Settings → Pages`，`Source` 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存
4. 一两分钟后访问 `https://你的用户名.github.io/portfolio/`

命令行的方式：

```bash
cd 解压后的文件夹
git init
git add .
git commit -m "portfolio site"
git branch -M main
git remote add origin https://github.com/你的用户名/portfolio.git
git push -u origin main
```

然后在 GitHub 网页里开 Pages（同上第 3 步）。

## 国内访问更快：Vercel / Cloudflare Pages / 腾讯云 COS

国内访客较多时，Netlify 和 GitHub Pages 有时会很慢。

**Vercel**（<https://vercel.com>）：注册 → Add New Project → 上传或连 GitHub 仓库 → 自动部署，给你 `xxx.vercel.app` 链接。免费额度够用。

**Cloudflare Pages**（<https://pages.cloudflare.com>）：同上，国内访问通常比 Netlify 稳一些。

**腾讯云 COS / 阿里云 OSS**（需要实名和一点费用，几块钱/月）：
- 建一个存储桶，权限设为「公有读」
- 开启「静态网站」功能，默认首页填 `index.html`
- 把文件全部上传
- 得到类似 `https://你的桶名.cos-website.ap-guangzhou.myqcloud.com` 的地址
- 想用自己的域名可以再绑定（国内域名需要备案）

---

## 想用自己的域名（比如 yangyuqing.com）

1. 在 Namesilo / 阿里云 / 腾讯云买一个域名
2. 在托管平台（Netlify / Vercel / Cloudflare）里添加自定义域名
3. 按提示去域名服务商加一条 CNAME 或 A 记录
4. 等 10 分钟到几小时生效，平台会自动配好 HTTPS

## 上传前你需要知道的三件事

**1. 首页文件必须是 `index.html`**
本站的 `index.html` 是封面入口页，`home.html` 是主页。不要把 `index.html` 改名，否则打开域名会 404。

**2. 所有路径都是相对的**
我已经确认过全站没有 `file:///` 或 `/Users/qi/...` 这类本地绝对路径，所以放在任何子目录下都能正常跑（比如 `https://xxx.com/portfolio/`）。

**3. 图片总量 7 MB**
首次打开会加载封面和首屏，其余图片用了 `loading="lazy"`（滚动到才加载），所以首屏不会卡。上传耗时主要在这 7 MB。

## 如果不想部署，只想临时给别人看

**方式一：直接发压缩包**
把 `杨雨晴作品集_网站.zip` 发过去，对方解压后双击 `index.html` 就能看（不联网也能看）。

**方式二：局域网临时分享**
你和对方连同一个 Wi-Fi，在这台电脑上执行：

```bash
cd 解压后的文件夹
python3 -m http.server 8000
```

然后把你电脑的局域网 IP 给对方，比如 `http://192.168.1.5:8000`。
查自己的 IP：`ipconfig getifaddr en0`（Wi-Fi）。

⚠️ 注意：这个地址只有关掉电脑或终端就会失效，只适合当面演示。

**方式三：做成 PDF 发简历**
浏览器里 `Cmd + P`，目标选「存储为 PDF」，网站本身带打印样式，导出来是一份排版干净的 PDF 作品集，适合投递用。

## 我的建议

| 用途 | 推荐 |
| --- | --- |
| 投简历、发给 HR，要一个长期链接 | **Netlify Drop** 拖一下就完事，最快 |
| 以后想继续改、想留版本记录 | **GitHub Pages** |
| 主要给国内的人看 | **腾讯云 COS** 或 **Vercel** |
| 只想私下给一两个人看 | 直接发 zip，或 `python3 -m http.server` |

个人作品集这类站点，Netlify Drop 通常 5 分钟就能拿到可以发出去的链接。
