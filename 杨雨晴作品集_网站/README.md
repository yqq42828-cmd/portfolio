## 左侧常驻目录

主页的目录是**固定在左侧的侧栏**，滚动时保持可见，随时可跳到其他板块：

- 桌面端（≥1181px）：固定于左侧、垂直排列，每条含序号 + 标题 + 一行提要
- 随滚动高亮当前阅读的板块（左侧朱砂竖线 + 标题变红）
- 底部有「回到顶部」
- 窄屏（≤1180px）：自动收起为顶部横向条，可左右滑动，当前项自动居中
- 内容区整体右移 244px，不影响正文宽度

## 入口封面页（index.html）

- 整屏是一个 `<a>`，**点击任意位置**进入主页（触屏滑动超过 24px 则不误触）
- 卡片「弹出」动效：从下方缩起 + 轻微过冲 + 落定，约 0.9s；随后文字逐条上升、印章盖下
- 桌面端有轻微鼠标视差（卡片随光标平移几个像素）
- 卡片内容：头像、姓名、英文名、一句话标签 + 座右铭「毋意，毋必，毋固，毋我」
- 右下角是个人介绍小卡（学历、本科院校、关注方向），不再是印章
- 键盘可用：回车或空格进入
- 全部动画用过渡（transition）实现，并加了兜底——脚本失效时卡片依然可见；系统开启「减少动态效果」时直接静默显示

## 图片显示原则

**全站图片一律不裁切。** 所有 `object-fit: cover` 与固定 `aspect-ratio` 已移除，图片按原始比例完整展示：

- 照片、效果图、印章、图表都按原生长宽比渲染
- 图组按相邻图片的相近比例配对，避免出现高低不齐的大片空白
- 头像在封面卡片内用 `contain` 完整显示，左右两侧用照片取样色（`#b39192 → #9d7c7d`）延展衔接

## 项目详情页结构

三个项目页统一按你要求的叙事顺序组织：

**封面 → 背景与调研 → 痛点 → 核心理念 → 方案框架 → 设计产出 → 成果**

- 顶部有粘性章节导航，滚动时自动高亮当前章节
- 封面区右侧是项目档案（身份／团队／场地／周期／赛事／产出）
- 结尾有「上一项目 / 返回全部作品」导航

## 设计说明

- **风格**：纸感米白底 + 墨色衬线标题 + 竹青与朱砂点缀，呼应两个文旅项目的视觉语言
- **字体**：标题用系统衬线（Songti SC / 思源宋体），正文用黑体，不加载外部字体
- **配色变量**：`assets/css/site.css` 顶部 `:root`，改 `--seal`（朱砂）、`--bamboo`（竹青）即可整体换色
- **响应式**：桌面 / 平板（≤1040px）/ 手机（≤720px）三档，已在 390px 宽度实测
- **无障碍**：支持 `prefers-reduced-motion`；带打印样式（`Cmd+P` 可导出 PDF）
